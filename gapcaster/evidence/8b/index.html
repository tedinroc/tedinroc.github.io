Measured · 2026-11-17 · Apple M5 Max, 128 GB

8B lean profile: half the memory, twice the speed.

The Stage I results used Qwen3.8-27B for shot facts. To test whether the pipeline can run on smaller hardware, we swapped the vision-language model for Qwen3-VL-8B-Instruct (8-bit MLX) and ran the same 2 min 20 s excerpt with the same code, prompts and thresholds. This is a real measured run, not a projection.

Honest read: the 8B profile fits more lines and runs far cheaper, but its shot facts are shallower and its verifier is weaker on hard cases (13/19 vs 15/17). Its description lines are shorter and occasionally less precise (e.g. "Mechanical flyer" for an airship). That is the trade-off a small model buys; the describer review step is where it gets caught. The 27B profile remains the quality option, and the 8B profile is the one that can run on a 16 GB machine.

Why it matters

Small is a measurement, not a slogan

The same orchestrator, the same prompts, one model swap: 13.7 GB instead of 33.2 GB, 50 s instead of 125 s per content minute. That is what makes a describer's laptop or a small studio's 16 GB card a realistic deployment target.

Environment note: the run used the repository's MLX path on macOS. Kokoro's espeak fallback was disabled for out-of-vocabulary words in this environment (a local library data-path issue), so a small number of rare words may have been skipped in speech; line timings and fit results are measured from the actual synthesized audio.
