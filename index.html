2nd place · ETH Shenzhen 2026 · Oct 2026

Upgrade Airlock

Every proxy upgrade passes two doors: a cooldown measured in blocks, and an on-chain clearance from a Chainlink CRE workflow that first attacks the new implementation in a simulator. An upgrade that fails the attack search gets a signed veto and never runs, even if the attacker holds the upgrade key. Live on Ethereum Sepolia, entered solo. Testnet only, not audited.

A voice AI agent on an ESP32-S3 AMOLED watch, built on xiaozhi-esp32 (MIT) and ESP-Claw (Apache-2.0), with my own Go voice gateway. A single-variable control run traced cut-off answers to a missing barge-in confirmation window, not speaker echo. One working prototype, not a product.
