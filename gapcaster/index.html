Audio description that fits the silences.

GapCaster drafts a timed, spoken description track for finished films. It finds the gaps between dialogue, writes to the exact time available, speaks and measures every line, rewrites what does not fit, and keeps a human describer in control. It runs on one local GPU — the video never leaves the machine.

Six stages, all local

No frontier API, no cloud upload, no account. The only network use is downloading open-weight models once.

01

Map the silences

Whisper word timestamps and Silero VAD independently mark dialogue. A silence is usable from 0.25 s after a line to 0.30 s before the next; long silences split at shot cuts.

02

Read the shots

A vision-language model returns JSON facts per shot: who, where, action, on-screen text, the key visual fact, confidence. A cast sheet keeps names consistent.

03

Write to budget

Narration is drafted for a word budget of the window at 2.6 words/s (3–18 words). Unread on-screen text is queued; credits and web addresses are filtered.

04

Speak and measure

Kokoro TTS speaks each line; its real duration is measured. If it overflows, the line is tried at 1.08× and 1.15×, then rewritten with the exact overflow, up to three rounds.

05

Gate and verify

Deterministic rules block camera language, speculation and first person. A verifier checks every claim against the shot facts on screen while the line plays; no verdict is flagged.

06

Human approves

The describer sees each line with its frame, facts, attempts and flags, then approves, edits or rejects. Export mixes only approved lines and re-times edited ones.

Why this is hard

AD is a timing craft

Most tools generate text and assume it will fit. Audio description has to fit a specific interval between two lines of dialogue without covering either. GapCaster treats that as a control loop: speak, measure, adjust, rewrite. Its output includes the timing evidence, so a human can check the machine instead of trusting it.

Built to be Human-Scale

The Mozilla Foundation Incubator's Human-Scale AI cohort asks for technology that is small, intentional and tailored. This is how GapCaster answers each.

Small.

One local acceleration device, open-weight models, no frontier API. Stage I: Qwen3.8-27B (8-bit) for shot facts, Whisper large-v3-turbo for dialogue, Kokoro-82M for speech; 33–34 GB peak. Stage II: one ASUS UGen300 (Intel Arc Pro B70, 32 GB), with a planned 8B profile for smaller hardware.

Intentional.

The film never leaves the machine. No accounts, no telemetry, no cloud calls. Every line carries the facts it came from, its drafts, fit attempts, style flags and verifier verdict. The describer can audit and reject; only approved lines are mixed. Code is MIT; model licences are recorded.

Tailored.

Designed for blind and low-vision viewers and the describers who serve them, around the constraint that defines AD: the gap. The next step is Mandarin and Taiwanese AD, co-designed with local listeners and describers — because a good line sounds different in each language and culture.
